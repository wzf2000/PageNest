# 使用 PageNest

## 安装与首次启用

要求 WordPress 6.0+、PHP 8.0+。

1. 在 仓库页面的 **Releases** 下载发行附件中的 `pagenest-版本号.zip`，选择安装包，而非 GitHub 自动生成的 Source code ZIP。
2. 在 WordPress 后台打开 “外观 → 主题 → 安装主题 → 上传主题”，上传 ZIP，安装并启用。
3. 在 “外观 → 菜单” 分配 “全站主导航”。站点标题与 Logo 在 “外观 → 自定义 → 站点身份” 配置。
4. 在 “外观 → 自定义 → PageNest 外观设计” 配置首页内容，发布后检查桌面和手机显示。

主题是独立经典主题，无需安装父主题。未配置专题或作者时不会自动导入示例文章；预览图是合成演示内容。站点图片由使用者上传，并确认使用权。

## 首页与站点外观

| 自定义器入口                       | 可配置内容                                 |
| ---------------------------------- | ------------------------------------------ |
| PageNest 外观设计 → 首页介绍       | 首页眉题、首页介绍、作者介绍；介绍支持换行 |
| PageNest 外观设计 → 首页背景       | 上传首页背景图片                           |
| PageNest 外观设计 → 首页专题       | 最多六个专题的名称与链接                   |
| PageNest 外观设计 → 首页作者       | 最多七位作者的姓名和头像                   |
| PageNest 外观设计 → 页脚信息       | 页脚标语、版权署名、可选备案号             |
| PageNest 外观设计 → 交流区         | 交流说明、交流链接及归档链接名称           |
| PageNest 外观设计 → 归档与关于链接 | 归档链接和关于链接的名称、地址             |
| PageNest 外观设计 → 登录与注册     | 登录背景图片与提示语                       |

所有主题设置节统一位于 “PageNest 外观设计”（英语界面为 “PageNest design”）面板，也可从 “外观 → PageNest” 进入对应设置。文案留空隐藏对应内容；链接名称和地址均需非空。归档地址默认指向文章列表，也可创建页面、选择 “文章归档” 模板，再填写该页面地址。旧 `pages/page-archives.php` 模板元数据继续兼容。

登录外观设置不会开启网站注册。是否允许注册仍由 WordPress 设置控制。

## 统一视觉设置与搜索

在 “外观 → 自定义 → PageNest 外观设计 → 全站视觉设置” 选择默认、暖纸或森林配色。背景、文字和强调色可单独覆盖，留空恢复预设；同时可调整基础字号、正文字号／行高、主要区块间距、圆角和最大宽度。1.2 保留已保存的显式设置值；未设置的默认配色采用新的暖白与灰绿外观，颜色留空时使用当前预设，不会自动写入或迁移设置。配色、字体与正文样式同步到 WordPress 编辑器和兼容预览；插件自有画廊、工具与登录页面仍由对应模块管理。

顶栏 “搜索” 可直接输入关键词，并筛选文章或页面；Escape 关闭并返回触发按钮，点击外部也会关闭。现有首页专题同时作为搜索面板与搜索结果页的快捷入口。搜索和 404 页面保留完整搜索表单；关闭 JavaScript 后仍可提交原生 GET 搜索。

搭配 Companion 1.3.0，在 “设置 → 内容发现与 SEO” 启用搜索建议。输入至少两个字符后显示最多八条公开结果，回车查看完整分页结果；建议服务故障不阻止提交。已配置且公开登记的工具另有筛选项。不需要第三方搜索插件。

## 首页编排与列表（1.2）

在 “PageNest 外观设计 → 模块与内容编排” 选择显示的模块，并填写 0–99 的顺序值；较小的排在前，相同值使用默认顺序。默认仍为专题、最新文章、作者，站点介绍始终保留。精选文章、最近更新、内容导览默认关闭。关闭模块保留设置与内容，取消专题后介绍区不会出现失效的专题跳转。

精选文章可按顺序选择四篇现有文章；内容导览可选四个现有页面，适合系列、专题和工具入口。选项包含最近更新的 100 条公开无密码内容及之前的有效选择；也可在 “内容 ID” 填写编辑页面地址中 `post=` 后的数字，选择更早的内容而无需修改文章。页面使用现有标题和手写摘要，不复制正文或自动生成工具登记。导览为空时不显示；取消公开或加密后自动移出推荐。最近更新按 WordPress 修改时间排序，修改标题等操作也会影响顺序；精选内容可与最新／更新列表重复，表示不同入口。专题设置可追加简介和状态说明，状态由站长维护，不从章节数量推断。

“PageNest 外观设计 → 列表与文章展示” 可选择标准卡片或紧凑列表、隐藏列表封面或文章大封面，并开启更新日期与估算阅读时长。列表封面开关不影响首页卡片；大封面开关只影响文章，不影响页面或附件。列表选项的默认开关保持，未自定义的视觉采用新版外观。阅读时长仅粗略统计源文本，不执行短代码、公式或外部服务，技术内容的实际耗时可能更长。分类／标签页使用原生分类说明作为简介，文章和分类数据仍由 WordPress 维护。

## 阅读与评论

正文目录根据 h1–h6 生成层级，可展开或收起分支，也可展开全部或收起全部。手机上目录位于正文顶部，默认收起；没有小标题时显示 “正文” 入口。滚动时标记当前阅读位置，锚点跳转会展开相应祖先分支。

文章页的 “阅读设置” 提供默认／18／20／22 字号、默认／紧凑／舒展正文宽度及默认／暖纸／暗色阅读配色；手机入口在文章上方。配色仅作用于文章面板，评论、插件面板和图片保持原样；不是全站暗色模式。偏好仅保存在当前浏览器的本地存储，不保存文章 URL、阅读记录或账户数据，不跨设备同步。恢复默认会清除偏好并使用站长设置；存储被禁用时仅本页生效，无 JavaScript 时保留默认阅读。密码文章与普通页面不提供该控件。

主题支持文章、页面、归档、搜索、404、原生评论和密码保护。默认相关文章来自同分类的公开文章；开发者可通过 [扩展接口](EXTENDING.md) 调整。

评论邮件通知、旧 Markdown 编辑器与公式兼容由独立的 PageNest Companion 提供。配套插件提供段落评论、章节顺序和点赞；经验、社交登录及其他工具可独立接入。

## 升级与旧设置

升级前备份文件和数据库。0.5 之后保持主题目录名 `pagenest`，使用发行安装包升级。

旧主题的设置、菜单、正文类名与锚点可由 PageNest Companion 的显式外部兼容配置承接。主题自身不猜测旧标识，也不在加载时迁移设置。切换前核对插件的兼容配置；切换后检查导航、首页、目录、登录外观与扩展入口。

## 配置中心、迁移与示例（1.2）

「外观 → PageNest」将视觉、首页、列表、登录和页脚设置整理为原生自定义器入口。点击后先预览，再通过自定义器发布设置。首页作者与专题各有独立入口；配置中心不自动创建文章、页面或媒体。

「下载视觉设置 JSON」只导出已保存的 `pagenest_appearance_*` 配色、三个颜色及六个尺寸设置。它不会导出站点地址、文案、文章／作者／媒体 ID、登录背景 URL、账户数据或 Companion 设置。没有保存过的视觉设置不写入导出文件；导入保留文件未列出的现有设置。颜色的空字符串表示使用所选配色，不能与缺省混为一谈。

迁移时下载 JSON，检查后在另一站的配置中心粘贴并点击「导入并保存视觉设置」。导入会立即保存文件列出的值；如需回退，先下载当前视觉设置或备份数据库。文件版本、未知键、错误类型、非法颜色、超界或不符合步长的数值都会拒绝整份文件，失败不部分保存。空设置对象不会写入数据库。文件大小上限为 16 KiB。导出与导入均要求管理主题权限、POST 表单和有效 nonce。

在区块编辑器打开「区块样板 → PageNest」，手动插入「专题介绍」「资源卡片」或「文章提纲」。这些示例只含原生标题、段落和分栏；请替换占位文字并自行添加链接。没有远程图片、演示文章导入或自动建页。

只读诊断显示 PageNest、WordPress、PHP 版本，当前资源清单与源文件／哈希文件的一致性，以及已加载的 Companion 本地接口。接口存在不代表可选模块已开启；实际开关在 Companion 中管理。诊断不检查远程服务、不展示私有配置或文件路径，也不会更新或修复文件。具有插件设置权限且 Companion 设置接口可用时，显示其原有设置页链接。

主题界面使用 WordPress `pagenest` 文本域；语言由站点／用户的 WordPress 语言设置决定。正文和站长已保存的自定义文案保留原内容，不随界面语言改变。

目前随包提供英语原文和完整简体中文（`zh_CN`）语言包，后台跟随当前用户语言，前台跟随站点语言。搜索提示、目录按钮和本地阅读偏好反馈也使用相同文本域；不加载外部翻译服务。其他语言回退英语；RTL 布局和其他语言尚未专项验收。Companion 及其他组件维护各自的语言包，主题语言包只覆盖主题界面。

## 1.2 外观

1.2.0 使用暖白与绿灰默认配色，以及系统衬线标题。已保存的显式背景、文字、强调色与尺寸值继续优先；未设置的颜色采用新默认外观，使用预设时采用该预设的当前颜色。暖纸和森林预设保留；阅读偏好仍只影响当前浏览器中的文章面板。

「外观 → PageNest」按阅读、首页编排和站点细节组织入口；自定义器的 PageNest 外观设计面板归组既有设置。导入／导出和本地只读诊断在次级折叠区，样板预览是说明示意，只有在编辑器手动插入并保存才创建内容。

搜索支持分类、相关度／更新时间排序；Companion 启用搜索时还提供系列筛选、命中摘要及可靠的作者标题位置。
摘要仅使用已保存静态内容，遇到短代码或无法确定的动态结构时保守退回文章链接，不执行内容回调。
Companion 的可选「我的阅读」启用后，顶栏出现入口；本机记忆仍需读者显式开启。

## 全站明暗与页面布局

在自定义器「全站外观」设置浅色、深色或跟随系统，默认仍为浅色；已有配色、手工颜色与尺寸值
保持不变。访客可通过顶栏「外观」选择此浏览器的全站偏好，「站点默认」会删除该本机覆盖。
浏览器禁止存储时仍可在当前页面切换；跟随系统会实时响应系统变化。文章内的字号、宽度与阅读
配色仍是独立偏好，可以只为正文使用暖纸或深色。

「页面布局」分别设置文章的标准／专注／宽版、专题的标准／概览／宽版、工具的标准／工作区／
紧凑布局；默认标准，沿用既有呈现。编辑文章或页面时，可在「PageNest 布局」逐篇覆盖；页面
用途仅控制展示，不会注册、启用工具或放宽访问。专注阅读保留目录、阅读设置与评论入口。布局
与明暗设置可随原视觉 JSON 导入／导出，省略的值继续保持原样。

主题外壳、搜索、阅读栏、Companion 弹层和登录页面使用语义配色变量。独立工具的游戏画布、
PDF 内容及第三方界面保留各自表达，不用全局反色滤镜修改图片和内容。
